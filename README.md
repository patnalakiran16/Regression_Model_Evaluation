Task 35: Regression Model Evaluation

Project Overview

This project focuses on evaluating a Linear Regression model using Python. I created a simple salary dataset based on years of experience and trained a regression model to predict salaries.

After training the model, I evaluated its performance using different error metrics to understand how accurately it predicts salary values.

Objective

The main objective of this task is to understand how to evaluate a regression model and measure the difference between actual and predicted values.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

Dataset Description

The dataset contains two columns:

Column| Description
Experience| Years of work experience
Salary| Salary in rupees

The dataset contains 10 sample records.

Steps Followed

1. Imported the required Python libraries.
2. Created a salary dataset using experience values.
3. Separated input features and target values.
4. Divided the dataset into training and testing data.
5. Created and trained a Linear Regression model.
6. Predicted salaries using test data.
7. Compared actual and predicted salary values.
8. Calculated model evaluation metrics.
9. Visualised the results using Matplotlib.

Evaluation Metrics

1. Mean Absolute Error (MAE)

MAE measures the average absolute difference between actual and predicted values.

2. Mean Squared Error (MSE)

MSE calculates the average squared difference between actual and predicted values.

3. Root Mean Squared Error (RMSE)

RMSE is the square root of MSE. It measures prediction errors in the same unit as the target variable.

4. R² Score

R² Score measures how well the regression model explains the variation in the target variable.

Output

The program displays:

- Salary dataset
- Actual and predicted salary values
- MAE value
- MSE value
- RMSE value
- R² Score
- Actual vs Predicted Salary graph

Conclusion

Through this task, I learned how to evaluate a Linear Regression model using different performance metrics. I also understood how to compare actual and predicted values to check model performance.
